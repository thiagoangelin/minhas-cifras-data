Album:    Neon Ballroom

Tuning: Db Ab Db Ab Db Db  
 
from standard: 
        -low E string tuned down 1.5 steps 
        -A and D strings down 0.5 step 
        -G string up 0.5 step 
        -B string up 1 step 
 
Legend: 
        h - hammer on  
        p - pull off  
        b - bend string up 
        r - release bend 
        / - slide up 
        \ - slide down 
        ~ - vibrato 
        t - tap (with strumming hand) 
        x - muted, struck string 
        * - palm mute
