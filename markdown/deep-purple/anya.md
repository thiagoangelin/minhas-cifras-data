=-=-= Legend =-=-= 
~  - Let ring (Hold for as long as possible) 
s  - Slide to required note 
p  - Pull off 
x  - Dead String 
[] - Continued Note from Last Bar 
=  - Staccato (Stop note immediately) 
_  - 1/16 Notes (1 underscore above the note) 
^  - Bend note 1/4   ^^^  - Bend note 3/4 
^^ - Bend note 1/2   ^^^^ - Bend note 1 Semitone. 
5+ - Bend 1 Whole Step (2 Semitones, Eg. fret 17 to 19) 
+5 - Pre-Bend note 1 Whole Step. 
PM - Palm mute (only mute notes that are underlined with a 
 dash [-])

already bent to the 7th. The way 
to do these bends is to bend towards you. Note that the 3  
doesn’t bend. This way you’re 
layering up the same pitch on both strings.
