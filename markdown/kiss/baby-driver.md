Kiss - Baby Driver 
 
Eb Tuning 
 
Key: 
/    = slide up 
\    = slide down 
b    = bend (whole step) 
b^   = bend (1/2 step) 
b^^  = bend (1 1/2 steps) 
pb   = pre-bend 
r    = release-bend 
r^   = release-bend half-step 
h^   = hammer-on 
p^   = pull-off 
~    = Vibrato 
*    = Natural Harmonic 
#(#) = Trill 
**   = Artificial Harmonic 
x    = Muted String (Palm Muting) 
X    = Muted String (Fretboard Muting) 
 
This is one of my favorite tracks off of "Rock And Roll  
Over". 
A pretty basic rhythm part with the same chords played by  
Ace & Paul 
in different positions. Ace's lead work is based primarily 
 on the G minor 
blues scale. He uses some cool double stop riffs and  
repeating bends 
to accentuate the lead.
