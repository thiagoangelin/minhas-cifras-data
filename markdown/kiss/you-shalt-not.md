Key: 
/    = slide up 
\    = slide down 
b    = bend (whole step) 
b^   = bend (1/2 step) 
b^^  = bend (1 1/2 steps) 
pb   = pre-bend 
r    = release-bend 
t^   = tap with righthand finger 
h    = hammer-on 
p    = pull-off 
~    = Vibrato 
*    = Natural Harmonic 
#(#) = Trill 
**   = Artificial Harmonic 
x    = Dead notes (no pitch) 
P.M. = Palm mute (- -> underneath indicates which notes) 
(\)  = Dive w\bar 
(/)  = Release w\bar 
Tp   = Tap w\plectrum
